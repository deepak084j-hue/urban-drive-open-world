# Urban Drive Open World v0.9

Free original browser-based 3D open-world driving prototype.

## New in v0.9: Aanya's Private Suite
- A cozy, warmly lit private room with a sofa, window, lamps, and a city-night mood.
- Press **H** while on foot to enter the suite once your bond with Aanya is at least 10%.
- Press **G** or use the on-screen button to spend a quiet romantic moment.
- Each moment increases bond by 10%, up to 100%.
- Press **H**, **Esc**, or the on-screen button to return to the city.
- Romance is non-explicit; both characters remain clothed.

## Existing features
- Dynamic day/night lighting, toggleable rain (**T**), and eight cash stashes.
- Traffic, pedestrians, missions, wanted stars, vehicle recovery.
- Aanya companion with walking animation, follow/wait modes, passenger-style rides, and date missions.
- Garage with custom paint (**C**), engine upgrades (**V**), handling upgrades (**B**), and repair (**N**).

## Controls
- **WASD / Arrow keys**: walk or drive
- **E**: enter / exit a nearby vehicle
- **F**: ask Aanya to follow, wait, or join a drive
- **G**: interact; inside the suite, spend a quiet moment
- **H**: enter / exit private suite
- **T**: toggle rain
- **C / V / B / N**: garage paint / engine / handling / repair
- **Shift**: sprint / boost
- **Space**: handbrake
- **R**: recover vehicle / return to city center
- **P**: pause
- **K**: save game
- **Esc**: close pause menu or exit the suite

## Run it
Upload `index.html` to your GitHub repository and enable GitHub Pages. Three.js is loaded from jsDelivr, so an internet connection is required. Desktop Chrome or Edge recommended.

This remains a stylized prototype, not a photorealistic commercial game.
