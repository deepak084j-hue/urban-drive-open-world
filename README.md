# Urban Drive v2.0

Browser-based 3D open-world driving prototype. Requires an internet connection for the Three.js CDN.

## v2.0 updates
- Added visible hug interaction in Aanya’s Private Suite (button or X).
- Added a gentle lift/carry pose with a short animated sway (button or Z).
- Retained the kiss scene (button or M).
- Added arm poses and affection animation state.
- Migrates save data from v1.9 and older supported versions.

## Install
Replace the repository's `index.html` with this version, commit, wait for GitHub Pages, then hard-refresh with Ctrl+Shift+R.
