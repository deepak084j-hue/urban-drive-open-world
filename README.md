# Urban Drive Open World v1.4

## Aanya expression upgrade
- Procedural eye blinking with varied intervals.
- Subtle head sway and animated smile.
- Two expression/mood choices in the City Phone: **Shy Smile** and **Happy Mood**.
- A soft pink accent light around Aanya during private mode.
- Existing facial geometry includes eyes, eyebrows, nose, smile, blush, earrings, hair and necklace.

## Existing features
- Private suite with visible 3D scene and floating hearts.
- City Phone (**Y**): daily reward, Aanya call and moods, taxi, fine payment, weather, snapshots, mobile mechanic.
- Career XP/levels, missions, cash stashes, traffic, pedestrians, wanted stars.
- Garage paint (**C**), engine (**V**), handling (**B**), repair (**N**).
- Save/load with **K**; v1.3 saves migrate into v1.4.

## Controls
- **WASD / Arrow keys:** walk or drive
- **E:** enter / exit nearby vehicle
- **F:** ask Aanya to follow, wait, or join a drive
- **G:** interact / private moment
- **H:** enter / exit private suite
- **Y:** open City Phone
- **T:** toggle rain
- **C / V / B / N:** garage paint / engine / handling / repair
- **Shift:** sprint / boost
- **Space:** handbrake
- **R:** recover vehicle
- **P:** pause
- **K:** save game
- **Esc:** exit suite or close pause menu

## Install
Extract the ZIP and replace `index.html` in your GitHub repository, then commit changes. Three.js loads from jsDelivr, so internet is required. Desktop Chrome/Edge recommended.
