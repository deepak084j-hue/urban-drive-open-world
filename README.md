# Urban Drive Open World v1.2

## Aanya private-scene visibility upgrade
The old private-mode screen covered the whole game. In v1.2, the room and both 3D characters remain visible, while a small translucent interaction panel sits in the lower-right corner. Aanya now has gentle idle movement and floating 3D heart particles during private mode. The camera is adjusted to frame both characters and more of the suite.

## Existing features
- Aanya companion, relationship progression, private suite, and non-explicit romantic moments.
- City Phone (**Y**): daily reward, Aanya call, taxi, fine payment, weather control, snapshots, mobile mechanic.
- Career XP/levels, cash rewards, contracts, traffic, pedestrians, wanted stars.
- Garage paint (**C**), engine (**V**), handling (**B**), repair (**N**).
- Local save/load with **K** and the pause menu; previous v1.1 saves migrate on load.

## Controls
- **WASD / Arrow keys:** walk or drive
- **E:** enter / exit nearby vehicle
- **F:** ask Aanya to follow, wait, or join a drive
- **G:** interact / private moment
- **H:** enter / exit private suite
- **Y:** open City Phone
- **T:** toggle rain
- **C / V / B / N:** garage paint / engine / handling / repair
- **Shift:** sprint / boost
- **Space:** handbrake
- **R:** recover vehicle
- **P:** pause
- **K:** save game
- **Esc:** exit suite or close pause menu

## Install
Extract the ZIP and replace `index.html` in your GitHub repository, then commit changes. GitHub Pages loads Three.js from jsDelivr, so internet is required. Desktop Chrome/Edge recommended.
