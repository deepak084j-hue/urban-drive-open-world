# Urban Drive Open World v0.5

A free, original browser-based 3D open-world driving prototype. Includes an adult fictional companion character named Aanya. This is not GTA V and is not affiliated with Rockstar Games.

## v0.5 upgrades
- Aanya companion NPC with stylized face, hair, outfit, arms, legs, shoes and simple follow behavior
- Companion can follow or wait (`F`)
- Friendly interaction and a rooftop date spot (`G` near Aanya or near the date spot)
- Bond meter and companion marker on minimap
- Multi-checkpoint missions, different vehicle handling, traffic, pedestrians, wanted stars
- Pause menu (`P`), local save (`K`), load via pause menu
- Expanded HUD and companion status

## Run free with GitHub Pages
1. Extract this ZIP.
2. In your existing repository, replace `index.html` with this version.
3. Commit changes.
4. Ensure GitHub Pages uses `main` and `/ (root)` in **Settings → Pages**.
5. Open the published Pages URL after deployment.

Three.js loads from jsDelivr, so internet is required. Desktop Chrome/Edge recommended. Save data stays in the current browser/device. This is a prototype with stylized procedural graphics and simple AI, not a commercial-scale open-world game.

## Controls
- WASD / Arrow keys: walk or drive
- E: enter / exit nearby vehicle
- F: call or ask Aanya to wait
- G: interact with Aanya or use the date spot near city center
- Shift: sprint or boost
- Space: handbrake
- R: recover/repair vehicle or return to center
- P: pause menu
- K: save game
- Esc: close pause menu
