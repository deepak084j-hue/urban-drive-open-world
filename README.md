# Urban Drive v2.1

A stylized browser-based open-world driving prototype.

## What's new in v2.1
- On-screen touch controls for phones/tablets: movement, enter/exit vehicle, Aanya companion, suite, and phone.
- Touch buttons use pointer events and release keys safely when the browser loses focus.
- Save system now writes `urbanDriveSaveV21` and migrates data from V20 and older supported save keys.
- Existing city, contracts, car upgrades, Aanya story quest, and private-suite romantic interactions retained.

## Run / deploy
Upload `index.html` to your GitHub Pages repository (replace the previous file), commit, wait for deployment, then hard-refresh. Internet is required to load Three.js from jsDelivr.

Desktop controls: WASD/arrows, E vehicle, F companion, Y phone, H suite, M kiss, X hug, Z lift in suite, Q story quest, K save, P pause.
